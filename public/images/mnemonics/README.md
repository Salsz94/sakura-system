# 📁 Carpeta de Mnemotecnias de Kana — SakiGo (サキゴー)

Ilustraciones para recordar la forma de los caracteres de Hiragana y Katakana.

## 📋 Ejemplos
* `m1_a.png` — Letra あ (Antena de radio)
* `m1_i.png` — Letra い (Dos anguilas)
* `m1_u.png` — Letra う (Hombre cargando bolsa pesada)
* `m1_e.png` — Letra え (Gimnasta)
* `m1_o.png` — Letra お (Golfista en el green)
