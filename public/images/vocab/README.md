# 📁 Carpeta de Imágenes de Vocabulario — SakiGo (サキゴー)

Coloca aquí tus ilustraciones y stickers en formato `.png` (con fondo transparente) o `.webp`.

## 📐 Especificaciones Recomendadas
* **Formato**: PNG transparente o WebP
* **Dimensiones**: 512 × 512 px (o 256 × 256 px)
* **Estilo**: Cyberpunk Sakura, sticker anime limpio, vectorial neon o pixel art.

## 📋 Nombres de Archivo Sugeridos
* `ramen.png` — ラーメン (Ramen)
* `sushi.png` — すし (Sushi)
* `gohan.png` — ごはん (Arroz / Comida)
* `pan.png` — パン (Pan)
* `mizu.png` — みず (Agua)
* `ocha.png` — おちゃ (Té verde)
* `osake.png` — おさけ (Sake / Alcohol)
* `hon.png` — ほん (Libro)
* `tsukue.png` — つくえ (Escritorio)
* `kuruma.png` — くるま (Auto)
* `densha.png` — でんしゃ (Tren)
* `eki.png` — えき (Estación)
* `ie.png` — いえ / うち (Casa)
* `gakkou.png` — がっこう (Escuela)
* `neko.png` — ねこ (Gato)
* `inu.png` — いぬ (Perro)
* `sensei.png` — せんせい (Profesor)
* `gakusei.png` — がくせい (Estudiante)
* `mado.png` — まど (Ventana)
* `anime.png` — アニメ (Anime)
* `manga.png` — まんが (Manga)
* `game.png` — ゲーム (Videojuego)

> La app detecta automáticamente la imagen por el nombre de la palabra (en romaji limpio). Si la imagen existe, se mostrará en la tarjeta de ejercicio; si no existe, la app seguirá funcionando normalmente en modo texto.
