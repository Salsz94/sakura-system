# 🎙️ AUDIOS DE PRONUNCIACIÓN — SAKURA SYSTEM

Guarda tus archivos de audio MP3 generados por IA en las siguientes subcarpetas.

## 📂 1. `public/audio/kana/`
Audios de caracteres individuales. Nombre del archivo = Romaji en minúsculas + `.mp3`.

### 🌟 Módulo 1: Vocales Puras y Fila Ka (Para Empezar)
- `a.mp3` → あ
- `i.mp3` → い
- `u.mp3` → う
- `e.mp3` → え
- `o.mp3` → お
- `ka.mp3` → か
- `ki.mp3` → き
- `ku.mp3` → く
- `ke.mp3` → け
- `ko.mp3` → こ

### 📜 Resto de Hiragana (Módulo 1)
- **Sa**: `sa.mp3`, `shi.mp3`, `su.mp3`, `se.mp3`, `so.mp3`
- **Ta**: `ta.mp3`, `chi.mp3`, `tsu.mp3`, `te.mp3`, `to.mp3`
- **Na**: `na.mp3`, `ni.mp3`, `nu.mp3`, `ne.mp3`, `no.mp3`
- **Ha**: `ha.mp3`, `hi.mp3`, `fu.mp3`, `he.mp3`, `ho.mp3`
- **Ma**: `ma.mp3`, `mi.mp3`, `mu.mp3`, `me.mp3`, `mo.mp3`
- **Ya**: `ya.mp3`, `yu.mp3`, `yo.mp3`
- **Ra**: `ra.mp3`, `ri.mp3`, `ru.mp3`, `re.mp3`, `ro.mp3`
- **Wa / N**: `wa.mp3`, `wo.mp3`, `n.mp3`

## 📂 2. `public/audio/vocab/`
Audios de palabras o vocabulario de ejemplo. Nombre = Romaji de la palabra en minúsculas + `.mp3`.

### Ejemplos Lección 1 (あ行):
- `ame.mp3` → あめ (Lluvia / Dulce)
- `ii.mp3` → いい (Bueno)
- `uta.mp3` → うた (Canción)
- `en.mp3` → えん (Yen)
- `oishii.mp3` → おいしい (Delicioso)
