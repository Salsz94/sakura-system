# Sonidos de Sakura System

Coloca aquí tus archivos de audio (`.mp3` recomendado) con estos nombres exactos:

| Archivo | Cuándo suena |
|---|---|
| `open.mp3` | Al entrar al dojo (login/registro exitoso) |
| `correct.mp3` | Al acertar un ejercicio |
| `wrong.mp3` | Al fallar un ejercicio |
| `level-up.mp3` | Al subir de rango (opcional, aún no conectado) |
| `exam-pass.mp3` | Al aprobar un examen de módulo (opcional, aún no conectado) |
| `exam-fail.mp3` | Al perder todas las vidas de un módulo — YOU DIED (opcional, aún no conectado) |

No necesitas tocar código: en cuanto el archivo exista en esta carpeta, sonará automáticamente. Si un archivo no existe, la app simplemente no reproduce nada (sin errores).

Los usuarios pueden silenciar todo el sonido desde Perfil → Ajustes.
